**규칙:**
1. 사용자 동의 없이 파일 생성/수정 금지
2. 간단한 작업 외에는 항상 계획 수립 후 승인받고 구현
3. 각 기능은 모듈식으로 구성, 모듈 구조 설명 문서(`docs/modules.md`) 필수 유지
4. 의문점 발생 시 임의 판단 말고 사용자에게 질문

**Why:** 사용자가 명시적으로 요청한 작업 방식. 무단 변경 시 불신 발생.

**협업 순서:**
1. Claude가 계획 수립
2. 사용자 + Gemini가 계획 검토 및 피드백
3. Claude가 피드백 반영 후 계획 수정
4. 사용자 최종 승인 → 구현

**How to apply:** 모든 작업 전에 이 순서를 따른다. 승인 전에 절대 파일을 건드리지 않는다.
